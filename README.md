# Matias Moretti — academic website

Static GitHub Pages website for Matias Moretti. The site is intentionally dependency-free: open `index.html` locally or serve the repository root with any static web server.

## Preview locally

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

GitHub Pages can publish directly from the `main` branch and repository root. PDFs in this repository remain available at their existing URLs.
